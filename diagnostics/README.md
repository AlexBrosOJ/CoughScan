# Диагностика распознавания CoughScan

Откройте https://colab.research.google.com/ → File → Upload notebook → CoughScan_diagnostics.ipynb.

## Порядок

1. Сделать короткую сессию: отдельно живой кашель, отдельно запись из динамика, отдельно фон без кашля. Отметить время; не форсировать кашель ради теста.
2. Сразу скачать `https://alexbrosoj-yam-134b.twc1.net/coughs/audio/all` и метаданные `https://alexbrosoj-yam-134b.twc1.net/records/all?limit=500&include_audio=true`. Доступность URL не проверена; они взяты из исходников. Не публиковать архивы с чужими разговорами.
3. Загрузить ZIP/WAV в notebook. Либо загрузить пару .keras/.pkl с сервера, либо включить DOWNLOAD_GITHUB_ARTIFACTS для файлов публичной main-ветки. Они могут отличаться от развёрнутых файлов; сверить SHA256.
4. Выполнить ячейки. Прослушать оригиналы и разметить их кнопками «Да, кашель / Нет кашля / Не уверен» прямо в Colab, сравнить original, enhanced, silence gate и базовый класс кашля YAMNet.
5. Прислать diagnostics.csv и размеченные примеры. Не выбирать финальный production-порог по этой же тестовой выборке.

## Подтверждено по исходникам

- Функции extract_features_new и fast_enhanced_check из присланного текста совпали с main.py в GitHub при AST-сравнении 17 ноября 2026.
- WAV ресемплируется в mono 16 kHz (это соответствует требованиям YAMNet), но используется только первая секунда.
- RMS < 0.02 (~−34 dBFS) отбрасывает аудио до модели. Нужно проверить, какие реальные кашли попадают под фильтр.
- Для N=16000 и сглаживания средним W=1000 отношение сглаженной |амплитуды| к глобальному RMS <= sqrt(N/W)=4 по неравенству Коши–Буняковского. Ветка >7.3 недостижима; при наличии пиков всегда штраф 0.82. Если пиков нет, штраф 0.75.
- ZCR с hop=256 и стандартным center=True даёт 63 значения. scipy.find_peaks может найти не более 31 внутреннего пика: условие <35 всегда истинно, штраф 0.9 неизбежен.
- При low_to_mid>0.27, наличии пиков и flatness<0.04 общий множитель =1.25*0.82*0.82*0.9=0.75645. Чтобы превысить THRESHOLD=0.75, исходная оценка должна быть >0.99147. Пример: 0.9 превращается в 0.680805 и считается отрицательным. Частота этой ветки на реальных записях ещё не измерена.
- MFCC — кепстральные коэффициенты; отношение первых коэффициентов не является напрямую отношением энергии низких и средних частот.
- Ошибки анализа возвращаются как probability=0/cough_detected=False, а upload добавляет status=success. Даже исправленная клиентская проверка HTTP/JSON не отличит такую серверную ошибку от отрицательного анализа. Исправлять сервер: ошибки -> соответствующий HTTP 4xx/5xx и status=error, без фиктивного отрицательного результата.
- База очищается от записей старше часа при каждом upload и startup, а не «раз в час». ZIP строится по оставшимся строкам БД. Старые WAV могут остаться сиротами и не попадать в ZIP; лимит 500 и очистка по БД их не видят. Для старых файлов нужен доступ к серверной папке cough_audio_storage, а не только HTTP ZIP.
- В присланном коде нет авторизации download/list/ZIP и очистки. Защитить эти маршруты перед сбором аудио внешних тестировщиков; не вставлять секреты в публичные Colab или GitHub.
- В requirements.txt GitHub не зафиксирован scikit-learn, хотя scaler десериализуется joblib. Для воспроизведения запросить pip freeze с рабочего сервера и обучающей среды.

## Упрощённый интерфейс

- В обновлённом notebook модель скачивается по умолчанию. При отсутствии model/scaler выполнение останавливается с понятным сообщением вместо молчаливой оценки только YAMNet.
- Разметка по одному WAV с кнопками и автосохранением в сессии, без ручного CSV. Можно скачать резервную копию ответов кнопкой.
- Если старый notebook уже открыт и WAV загружены, скопируйте весь Colab_labeler.py в новую кодовую ячейку и выполните её — повторный анализ не нужен для прослушивания.
- Для старой сессии без модели скопируйте Colab_load_model.py в новую ячейку, выполните, затем повторите исходную ячейку def diagnose(path) с циклом анализа. Это исправляет отсутствие original/enhanced, но не изменяет продакшен.
- В старой сессии пропустите прежние ячейки скачивания и загрузки labels.csv: они больше не нужны.
- Проверены синтаксис notebook и автономных ячеек, наличие обработчиков кнопок, отсутствие автоматического files.download в разметчике. Визуальный запуск Colab/виджетов из локальной среды не выполнялся.
